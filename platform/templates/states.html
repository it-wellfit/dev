按鈕（Button）

Hover／Focus／Active／Disabled 狀態各自獨立；鍵盤 Tab 巡覽時顯示可見焦點環（--focus-ring，對比 ≥ 3:1）。

Default／Hover／Focus 由 CSS 呈現；未填送出時瀏覽器標記 :user-invalid（紅框＋提示）。

資料八態（Eight Data States）

八態錨點：data-state-empty / zero / loading / partial / stale / denied / error / conflict——文案互異、各含下一步，供驗收與新頁面對照（G1.1/WP-08）。

載入中（Loading）

資料載入中…（僅在 >300ms 時顯示；尊重 reduced-motion）

可能原因：後端服務未啟動或連線中斷。請確認服務狀態後重試；若持續失敗，請聯絡系統管理員。

部分不可用（Degraded／Partial）

AI 決策服務暫停

規則引擎不受影響，登帳與查詢照常運作；服務恢復後本區塊回到完整狀態。

空狀態（Empty）

尚無資料 未知或無資料一律以「—」呈現，不以範例數字冒充真實帳務。

零結果（Zero Result）— 有資料但篩選無相符

沒有符合目前條件的項目

資料庫中有其他紀錄，但沒有一筆符合目前的篩選條件；與「尚無資料」（全新空庫）不同。請調整關鍵字或日期範圍後再試。

無障礙與設計系統

  • 跳至主要內容（skip-link）、語義地標（header／nav／main／footer）、標題層級 h1→h2→h3 無跳級。
  • 可見焦點：鍵盤 Tab 全頁可巡覽，焦點環對比 ≥ 3:1。
  • 動態偏好：prefers-reduced-motion 時停用非必要動畫。
  • 色彩對比：文字 ≥ 4.5:1、大字 ≥ 3:1（WCAG 2.2 AA）。
  • 設計系統原始檔：design-system.css（Cascade Layers＋Design Tokens）。
