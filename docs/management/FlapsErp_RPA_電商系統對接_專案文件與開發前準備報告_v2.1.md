## 1. 專案概覽

### 1.1 專案目標與成功指標

本專案以免費、開源、本機優先方式，將輔翼 ERP (FlapsErp，Electron 桌面版，安裝於 `C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErp`) 與電商系統打通，實現訂單、庫存、客戶、出貨與退貨資料的自動化對接，減少人工重複輸入與對帳。

| 目標 ID | 目標描述 | 量化成功指標 (KPI) | 驗證方法 |
|---------|----------|-------------------|----------|
| G1 | 訂單/庫存/客戶資料雙向自動對接 | 單筆對接 ≤ 5 秒 (API) 或 ≤ 30 秒 (UI RPA) | 效能測試報告，樣本 ≥ 50 筆 |
| G2 | 資料一致性 ≥ 99.5% | 雙端比對差異率 ≤ 0.5%，差異進入人工複核佇列 | 每日對帧報告，稽核抽查 |
| G3 | 系統可用性 ≥ 99%（24/7 口徑） | 月計劃停機 ≤ 4.32 小時＋非計劃停機 ≤ 1 小時（合計 5.32 小時 ≤ 月 1% = 7.2 小時） | 監控系統報告 |
| G4 | 失敗自動恢復 ≤ 5 分鐘 | 連續失敗 5 次觸發斷路器，自動重試 ≤ 3 次並告警 | 故障注入測試，告警紀錄 |
| G5 | 零機密資料外洩 | 傳輸 TLS 1.2+，日誌敏感欄位遮蔽率 100% | 滲透測試報告，日誌掃描 |
| G6 | 授權成本為零 | OpenRPA (MPL-2.0) + Windmill 原生二進位，無商業授權 | 授權清單審核 |

### 1.2 範圍與邊界

**納入 (In Scope)：**
- FlapsErp 與電商系統之間訂單、庫存、客戶、出貨、退貨資料的自動讀取與寫入。
- 三層對接模式：優先 API/服務層；次選 OpenRPA 桌面 UI 自動化 (winax/COM)；最後資料庫直讀做補強對帳。
- 繁體中文編碼轉換（內部 UTF-8 ↔ 電商系統 CP950/Big5，透過 iconv-lite）。
- OpenRPA + PowerShell + Windmill（原生二進位部署，不含 Docker）。
- 冪等控制（穩定業務鍵：訂單／出庫單／退貨單編號等）、雙端對帧、異常佇列與人工複核。
- 開發/測試/生產環境建置；發布、監控、備份、回滾 SOP。

**排除 (Out of Scope)：**
- 電商系統端原始程式碼修改或逆向工程；微服務、Kubernetes、Kafka、向量資料庫、複雜事件架構。
- 商業 RPA 授權 (UiPath/Automation Anywhere 企業版)、Docker 容器化。
- 非訂單/庫存/客戶對接之其他業務模組；電商前端頁面與行銷功能。

## 3. 系統分析與設計

### 3.1 系統架構圖

四層架構：
1. **使用者層**：電商使用者（下單/查詢）、FlapsErp 操作員（出庫/對帳）
2. **電商系統層**：電商前端 (Web/APP)、電商 API (REST/SOAP/GraphQL)、電商資料庫
3. **自動化對接層 (RPA)**：OpenRPA 工作流（桌面 UI 自動化 / API 呼叫）、PowerShell 膠合腳本（資料搬移 / 編碼轉換 / 告警）、Windmill 排序平台（定時觸發 / 斷路器 / 重試）
4. **輔翼 ERP 層**：FlapsErp 桌面程式（Electron + Vue2）、winax / COM（原生 ActiveX 物件）、ffi-napi / DLL（原生函式呼叫）、iconv-lite（UTF-8 ↔ CP950/Big5）
5. **本地儲存層**：SQLite / CSV（對帧資料＋稽核日誌）、加密備份檔案（AES-256）

### 3.2 資料流程與交易規格

| 交易代號 | 交易名稱 | 幂等鍵 | 頻率 | 延遲要求 |

| TXN-02 | FlapsErp 出庫 → 電商系統 | FlapsErp 出庫單編號 | 事件驅動 | ≤ 5 秒 |
| TXN-03 | 庫存同步 | 商品ID+倉庫別+快照日期 | 每日 | ≤ 5 分鐘 |
| TXN-04 | 客戶同步 | 電商客戶ID | 每日 | ≤ 5 分鐘 |
| TXN-05 | 退貨同步 | 電商退貨單編號 | 每日 | ≤ 30 秒 |

### 3.5 技術選型與選型理由

| 類別 | 選定技術 | 授權 | 選型理由 |
|------|----------|------|----------|
| RPA 工具 | OpenRPA | MPL-2.0 | Windows 原生、支援 winax/COM、可內嵌 PowerShell/C#、免費開源 |
| 排序與協調 | Windmill | 原生二進位 (sc.exe) | 專案既有架構，不需 Docker |
| 膠合腳本 | PowerShell | 5.1 | Windows 原生 |
| 編碼處理 | iconv-lite | FlapsErp 內建 | 支援 CP950/Big5 ↔ UTF-8 |
| 本機儲存 | SQLite / CSV | 本機檔案 | 輕量、無伺服器 |
| 日誌與稽核 | 本機加密檔案 | AES-256 | 符合本機優先與稽核保留 ≥ 1 年 |

- 程式碼註解覆蓋率 ≥ 80%；RPA 模組化 ≤ 500 行。

## 11. 系統流程最佳化建議

- **對接模式優先級**：API > OpenRPA UI > 資料庫直讀（補強對帳）。
- **編碼統一**：內部 UTF-8，交換時 iconv-lite 轉換 CP950/Big5。
- **冪等與對帧**：穩定業務鍵為冪等鍵；每日 02:00~06:00 雙端對帧。
- **RPA 主機穩定**：關閉睡眠、固定解析度 1920×1080 100% 縮放、每週重啟。
- **智能化漸進**：Phase 1 基礎對接＋對帧；Phase 2 可加入 Isolation Forest 輕量異常偵測。
- **文件即程式碼**：架構圖、介面矩陣、RPA 工作流與 PowerShell 腳本均納入版本控制。
- **狀態機對映**：建立電商訂單狀態與 FlapsErp 訂單狀態標準對映表。
