# PRODUCT VISION — 產品願景

> Phase 0 交付。依據：docs/product-solution.md（四大核心假設）、PRD.md、市場研究（2026-11-04）。

## 願景陳述

讓中小企業的會計登帝從「手動記帳、事後核對」變成「**30 秒完成一筆可稽核、可解釋、平衡的複式分錄**」——以零 JavaScript 的單機安全工作台，提供證據導向的帳務自動化。

## 核心問題（四大假設）

| # | 問題 | 本產品的答案 |
|---|------|--------------|
| H1 | 帳務資訊取得成本高 | 儀表板＋月報＋CSV 一次到位 |
| H2 | 流程斷裂（記帳與核對分離） | 借貸平衡強制＋稽核軌跡一體 |
| H3 | 對 AI 信任不足 | **依據卡**：每個預填標示來源規則；AI 僅建議需人工覆核 |
| H4 | 整合維護成本高 | 單一執行檔＋SQLite 檔案式 DB；零 JS 無前端建置鏈 |

## 差異化（對照 2026 市場）

| 市面產品 | 本產品差異 |
|---|---|
| AI 黑箱自動分類（QuickBooks/Xero） | **規則表 100% 可推導**＋AI 僅建議（schema 閘門＋人工覆核） |
| SaaS 雲端（資料外流疑慮） | **本機單檔資料庫**，資料不出機器 |
| 重前端（Node 建置鏈） | **零 JavaScript**——審計人員可逐行驗證表現層 |
| 訂閱制鎖功能 | 單機核心功能完整交付 |

## 目標使用者

| 角色 | 需求 |
|------|------|
| 記帳人員 | 快速登帳、錯誤即時提示 |
| 財務審核 | 平衡驗證、稽核軌跡、報表 |
| 企業主 | 資料在本機、無訂閱依賴 |
| IT/稽核 | 零 JS 可審計、WAL 備份簡單 |

## 成功指標

1. 一筆分錄登帳 ≤ 30 秒（含驗證）。
2. 全部金額運算可推導（整數分，零浮點）。
3. 87+ 自動化測試護欄，基線四項常態 EXIT=0。
