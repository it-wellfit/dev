## 2. 端到端流程（5 步）

### Step 1: Windmill 排程觸發

**排程**：每日 02:00（離峰時段，避免影響使用者作業）

**Windmill Flow 定義**（YAML）：

```yaml
# windmill/flows/erp-batch-daily.yaml
name: ERP Batch Daily
description: Daily ERP batch processing via Wellfit
schedule: "0 2 * * *"
steps:
  - name: run-mtrix
    type: script
    language: powershell
    code: |
      & "C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErp\...\run-mtrix-pipeline.ps1"
      if ($LASTEXITCODE -ne 0) { throw "MTRIX pipeline failed" }
  - name: run-shopee
    type: script
    language: powershell
    code: |
      & "C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErp\...\run-shopee-pipeline.ps1"
      if ($LASTEXITCODE -ne 0) { throw "Shopee pipeline failed" }
  - name: open-flapserp
    type: script
    language: powershell
    code: |
      $params = @{ action = "import"; file = "C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErpData\import\latest.csv" }
      $b64 = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes(($params | ConvertTo-Json -Compress)))
      Start-Process "flapserp://$b64"
  - name: notify
    type: script
    language: powershell
    code: |
      # Success notification
      Send-MailMessage -To "ops@company.com" -Subject "ERP Batch OK" -Body "Daily batch completed"
```

**驗收**：Windmill 排程可觸發，exit 0。

### Step 2: Wellfit 批次處理

**執行命令**：

```powershell
# MTRIX 五檔處理
wellfit.exe mtrix --dir "C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErpData\MTRIX\delivered" `
  --report "C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErpData\MTRIX\report.json" `
  --batch "ERP-BATCH-$(Get-Date -Format 'yyyyMMdd')" `
  --db "C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErpData\ledger.sqlite"

# 蝦皮訂單處理
wellfit.exe shopee --dir "C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErpData\Shopee\orders" `
  --out "C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErpData\Shopee\import.csv" `
  --report "C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErpData\Shopee\report.json" `
  --batch "ERP-BATCH-$(Get-Date -Format 'yyyyMMdd')" `
  --db "C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErpData\ledger.sqlite"
```

**Wellfit 處理管線**（每條資料流）：

1. **ColumnContract 名稱解析**：以欄位名稱解析（非序位），必填欄位缺失 → 硬失敗
2. **ScaledDecimal 整數分**：所有金額轉為整數分（禁浮點）
3. **冪等帳本註冊**：批次 ID + 內容雜湊去重；重複批次 → 拒絕（exit 1）
4. **Release Gate 驗證**：欄位契約 + 金額守恆 + 參照完整性
5. **產出**：8 欄匯入 CSV + report.json + ledger 記錄

**驗收**：exit 0，產出檔案存在，ledger 記錄正確。

### Step 3: flapserp:// 開頁（人工確認）

**PowerShell 輔助函式**：

```powershell
function Open-FlapsErpImport {
    param(
        [Parameter(Mandatory)]
        [string]$FilePath,
        [string]$Action = "import"
    )
    $params = @{
        action = $Action
        file = $FilePath
        timestamp = (Get-Date).ToString("o")
    }
    $json = $params | ConvertTo-Json -Compress
    $b64 = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($json))
    $uri = "flapserp://$b64"
    Write-Host "Opening: $uri" -ForegroundColor Cyan
    Start-Process $uri
    return $uri
}

# 使用
Open-FlapsErpImport -FilePath "C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErpData\Shopee\import.csv"
```

**人工確認步驟**：
1. FlapsErp 開啟指定作業頁（應付憑單匯入）
2. 使用者確認匯入檔案路徑正確
3. 使用者點擊「匯入」按鈕
4. FlapsErp 顯示匯入結果（成功/失敗）

**驗收**：FlapsErp 開啟指定頁面，使用者可完成匯入。

### Step 4: 匯入回執回收

**FlapsErp 匯出回執**：匯入完成後，FlapsErp 可匯出回執 CSV（含匯入結果、錯誤列、處理時間）。

**Wellfit 對帳**：

```powershell
# Wellfit 對帳命令（待實作）
wellfit.exe reconcile --erp-report "C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErpData\FlapsErp\receipt.csv" `
  --ledger "C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErpData\ledger.sqlite" `
  --batch "ERP-BATCH-$(Get-Date -Format 'yyyyMMdd')"
```

**對帳邏輯**：
1. 讀取 FlapsErp 回執 CSV
2. 與 Wellfit ledger 對比（批次 ID + 內容雜湊）
3. 計算差異率（目標 ≤ 0.5%）
4. 產出對帳報告（claims-vs-evidence 格式）

**驗收**：回執與 ledger 對帳一致，差異率 ≤ 0.5%。

## 3. 量測與驗收

### 3.1 量測指標

| 指標 | 目標 | 量測方式 |
|---|---|---|
| 端到端耗時 | < 5 min（不含人工確認） | Windmill step 計時 |

## 4. 回滾程序

### 4.1 回滾步驟

1. **停用 Windmill 排程**：Windmill UI → Flow → Disable
2. **刪除 ledger 批次**：`DELETE FROM batches WHERE batch_id = 'ERP-BATCH-YYYYMMDD'`
3. **刪除產出檔案**：`rm -rf C:\SYSTEM_PROGRAM_DIRECTORY\FlapsErpData\*\import.csv`
4. **FlapsErp 端無變更**：所有寫入走官方匯入入口，回滾=不匯入

### 4.2 驗證方式

- `git status`（Wellfit repo）乾淨
- ledger 重跑被拒（冪等性驗證）
- FlapsErp 功能正常（手動操作驗證）
