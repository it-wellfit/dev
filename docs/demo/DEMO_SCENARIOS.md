# DEMO SCENARIOS — 展示場景腳本

> 每個場景標示：登入帳號、操作步驟、預期結果、展示價值。全部可在 `reset-demo.ps1` 後重複執行。

## Scenario 1 — 標準登帳（核心價值：複式記帳＋平衡強制）

**帳號**：demo-finance
1. 登入 → 導航「新增交易」→ 步驟 1 選「現金支出」
2. 步驟 2：借方 `SUPPLIES-EXP`、貸方 `CASH-001`、金額 `3200`、摘要「[DEMO] 文具補充」
3. 故意將貸方改成與借方相同 → 顯示「借貸兩方不得為同一科目（規則 R-BALANCE）」
4. 修正 → 步驟 3 確認摘要 → 送出 → 303 回交易清單

**預期**：清單出現新交易；audit_log 新增 TRANSACTION_POSTED。

## Scenario 2 — RBAC 權限展示（安全）

**帳號**：demo-viewer
1. 登入 → 導航無「使用者管理」
2. 嘗試登帳 → 403「您沒有建立交易的權限（規則：LEDGER_WRITE）」

**帳號**：demo-finance → 登帳成功（對照）

## Scenario 3 — 兩段式 CSV 匯入（資料獲取）

**帳號**：demo-finance
1. 準備 CSV：首行標題＋2 合格列＋1 錯誤列（金額 `0.001`）
2. 「快速匯入」→ 上傳 → 預檢報告：2 合格、1 錯誤（小數位數過多）
3. 確認匯入 → 僅 2 筆登帳；再次確認 → 409

**展示價值**：乾跑無副作用、錯誤不阻塞合格列、重放防護。

## Scenario 4 — 非結構化解析＋依據卡（智慧輸入）

**帳號**：demo-finance
1. 「草稿解析」→ 貼上「2026-11-20 支付租金 15,000 元 現金→租金費用」
2. 解析 → 草稿頁顯示日期/金額/借貸＋**依據卡**（命中規則）
3. 採用 → 精靈步驟 2 已預填 → 修正 → 送出

**展示價值**：系統比使用者更懂規範；每個預填可解釋。

## Scenario 5 — 帳號生命週期（管理＋安全）

**帳號**：admin
1. 使用者管理 → 建立帳號 `demo-temp`（STORE）
2. 停用 `demo-temp` → 該帳號會話立即失效
3. 重設 `demo-viewer` 密碼 → 舊密碼失效、稽核 PASSWORD_RESET

## Scenario 6 — 唯讀對比（可解釋報表）

**帳號**：admin
1. 月報表（2026-11）→ 借貸合計相等（平衡不變量）
2. 下載 CSV → 整數分資料
3. 樞紐分析 → rows=account × cols=month
4. 平行座標投影 → 每科目一條折線
